# Winters Job Finder — Project State

> Last updated: 2026-04-01

## Current Iteration: v0.5

### What Works
- **Career pages collector**: Queries Greenhouse, Lever, and Ashby public JSON APIs for all 76 supported companies (85 total minus 8 Workday + 1 Rippling). Filters to product-leadership titles. Returns full job descriptions for better scoring.
- **Adzuna collector**: Queries 8 title variants across 2 locations (Seattle + Remote), filters to Seattle metro/remote
- **Remotive collector**: Queries product category, filters to senior titles, strips HTML
- **Scoring engine**: 0-100 scale across title/skills/experience/industry with penalties
- **HTML digest**: Styled email with score bars, skill pills, flag badges, top-10 ranking
- **Email delivery**: Brevo SMTP with DKIM+DMARC-verified sender (michaeladamwinters.com)
- **SQLite persistence**: Dedup by SHA-256 hash, upsert, history queries
- **GitHub Actions**: Daily cron at 7am PT + manual dispatch, commits jobs.db back to repo
- **Profile loading**: Supports both local file and PROFILE_JSON env var for CI

### What's Stubbed
- `output/` directory — Referenced in workflow artifacts but not yet generated by pipeline

### Known Issues
- **Remotive returns 0 product jobs**: The category endpoint sometimes has no listings. Not a bug — depends on their inventory.
- **Node.js 20 deprecation warning** in GitHub Actions: Actions will be forced to Node.js 24 starting June 2, 2026. Non-blocking.
- **Workday/Rippling companies (9)** not queryable: No public JSON API. These companies are skipped by career_pages collector.
